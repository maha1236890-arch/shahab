# نظام الحضور والغياب

برنامج سطح مكتب لإدارة حضور وغياب الموظفين، مبني بـ Python + tkinter + SQLite.

---

## المتطلبات

- Python 3.8 أو أحدث
- tkinter (مُثبَّت مع Python افتراضياً)

## التثبيت

```bash
cd ~/attendance_system

# تثبيت المكتبات المطلوبة
pip install -r requirements.txt
```

> **ملاحظة:** المكتبات `openpyxl` و`reportlab` مطلوبة فقط لتصدير التقارير.  
> البرنامج يعمل بدونها، لكن زر التصدير سيُظهر رسالة خطأ.

---

## التشغيل

```bash
python main.py
```

**بيانات الدخول الافتراضية:**
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

---

## الميزات

| التبويب | الوظيفة |
|---------|---------|
| لوحة التحكم | إحصائيات اليوم (حاضر / غائب / متأخر / إجازة) |
| الموظفون | إضافة، تعديل، حذف الموظفين + بحث |
| تسجيل الحضور | تسجيل الحضور اليومي لجميع الموظفين بنقرة واحدة |
| التقارير | تقارير بتصفية التاريخ، القسم، الموظف + تصدير Excel/PDF |
| المستخدمون | إدارة حسابات المستخدمين (أدمن فقط) |

---

## هيكل الملفات

```
attendance_system/
├── main.py          ← نقطة البداية (نافذة تسجيل الدخول)
├── admin_panel.py   ← النافذة الرئيسية بالتبويبات
├── database.py      ← عمليات قاعدة البيانات SQLite
├── export_utils.py  ← تصدير Excel و PDF
├── requirements.txt ← المكتبات المطلوبة
└── attendance.db    ← قاعدة البيانات (تُنشأ تلقائياً)
```

---

## ملاحظات

- قاعدة البيانات `attendance.db` تُنشأ تلقائياً عند أول تشغيل.
- كلمة المرور مُشفَّرة بـ SHA-256.
- يدعم تصدير PDF بالعربية إذا كان الخط `NotoSansArabic` أو `DejaVuSans` مثبَّتاً.
