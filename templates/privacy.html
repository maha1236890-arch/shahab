1. البيانات التي يجمعها التطبيق

يعمل تطبيق شهاب بشكل كامل على جهاز المستخدم دون الاتصال بأي خادم خارجي. جميع البيانات (بيانات الموظفين، سجلات الحضور، الإعدادات) تُخزَّن محلياً في قاعدة بيانات على الجهاز فقط.

2. مشاركة البيانات

لا يُشارك التطبيق أي بيانات مع أطراف ثالثة. لا توجد اتصالات بالإنترنت، ولا تحليلات، ولا إعلانات.

3. البيانات الشخصية

يخزّن التطبيق بيانات الموظفين (الاسم، الرقم الوظيفي، القسم) لأغراض إدارة الحضور فقط. يتحمل مشغّل البرنامج مسؤولية حماية هذه البيانات وفق قوانين حماية البيانات المعمول بها في بلده.

4. الأمان

تُحمى البيانات بكلمة مرور للدخول. يُوصى بعمل نسخ احتياطية دورية من داخل التطبيق.

5. التواصل

لأي استفسار بخصوص الخصوصية، يرجى التواصل مع المطوّر عبر: MGG Software

Privacy Policy (English) Last updated: May 2026
1. Data Collection

Shahab operates entirely on the user's local device with no external server connections. All data (employees, attendance records, settings) is stored locally in a database on the device only.

2. Data Sharing

The application does not share any data with third parties. There are no internet connections, no analytics, and no advertisements.

3. Personal Data

The application stores employee data (name, employee ID, department) solely for attendance management purposes. The operator of the software is responsible for protecting this data in accordance with applicable data protection laws.

4. Security

Data is protected by a login password. Regular backups are recommended using the built-in backup feature.

5. Contact

For any privacy inquiries, please contact the developer: MGG Software
